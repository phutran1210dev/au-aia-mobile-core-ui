# AIA Everest

AIA Everest is a licensed AIA font, so its files are not committed (`.gitignore`). This README keeps the folder in Git, because the iOS project copies the folder into the app.

To preview headings in AIA Everest, put these four files here, then rebuild the example app:

- `AIAEverestRegular.ttf` (weight 400)
- `AIAEverestMedium.ttf` (weight 500)
- `AIAEverestBold.ttf` (weight 700)
- `AIAEverestExtraBold.ttf` (weight 800)

Each file is named after the PostScript name inside it. Without the files, the app builds and headings fall back to the system font. The root README explains where to get them.
