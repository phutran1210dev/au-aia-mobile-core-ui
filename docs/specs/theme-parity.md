# Theme parity

This spec tracks how far the theme config of `@au-aia/mobile-core-ui` matches the reference model's Customize Theme API (version 6.6.5, credited in [Prior art](../tokens.md#prior-art)), adapted to React Native. Token names in the seed, map and alias layers are identical to the reference model's. It started as the Task C, Part 1 audit; the status columns are updated after every Part. The token inventory comes last because of its length.

## Status after Part 2a

- **Capabilities**: of 23 rows, 7 have, 9 partial, 3 missing and 4 do not apply on React Native.
- **Tokens**: of the 234 tokens the reference publishes (47 seed, 106 map, 81 alias), 115 exist, 105 are missing and 14 are left out on purpose (13 preset colors and `wireframe`).
- **Figma**: Qi's `AIA Typography` collection provides every typography default. Radius, spacing and shadows wait for the Figma links in D9.
- **Next**: Part 2b needs the DDS: Components v3.2.1 link. Part 3 can start without it, except for the shadows.

## 2. Figma values for non-color tokens

Both files were read on 2026-10-03 with the Figma MCP. Qi has typography variables; neither file has spacing, radius, size or motion variables, and the DDS shadow values are unread.

### Qi tokens – AIA

Qi has two variable collections: `Colours` (115, in the palette) and `AIA Typography` (54 variables in 10 language modes, `EN` by default). It has no local text or effect styles. The library takes `EN`, body and Mobile values; [docs/tokens.md](../tokens.md#typography-tokens) lists each token they fill. Desktop headlines (48/56, 40/48, 32/42, 28/36, 24/32, 20/28) stay out. The other language modes change sizes, line heights, letter spacing and families, and wait until an app ships one of those languages.

### DDS AU v2.0.11

A search of the library finds no spacing, radius or size variables, and `use_figma` on this file needs a Full Figma seat. It has text styles (`Headings/Desktop/*`, `Headings/Mobile/*`, `Body/*` with `Strong` and `Link` variants) and effect styles `Box Shadow/4pt`, `6pt`, `12pt` and `24pt`. No CLAUDE.md node uses the shadows or the Mobile headings, so those values are unread (D9).

### DDS: Components v3.2.1

A separate published library, now a design source in CLAUDE.md with its link still missing. Its `Semantic tokens` collection has `Spacing/spacing-none`, `2xs`, `xs`, `sm`, `md`, `lg`, `xl`, `2xl` to `7xl` (13 steps) and `Border/Border radius/radius-none`, `sm`, `md`, `lg`, `round`; its `Brand mapping` collection has per-component radii. Search returns names only.

## 5. Token inventory

This section lists all 234 tokens the reference publishes, grouped by layer and category. How to read the columns:

- **Status**: have (public today), missing, or N/A (left out on purpose; the note says why)
- **Part**: the Part that adds the token; 1 means it existed before Task C, and out means it is left out
- **RN type**: the TypeScript type on React Native. dp is the density-independent unit of RN styles
- **Default**: the value with no overrides. Interim marks a value design has not confirmed: it carries `@interim pending design` and an open question in docs/tokens.md
- **Default source**: Figma (a Qi or DDS path; nearest means the closest Qi value, not an exact match), derived (computed from the named tokens, as the reference computes it) or reference (the reference model's default)
- **Hover tokens** stay for parity and go unused on touch screens
